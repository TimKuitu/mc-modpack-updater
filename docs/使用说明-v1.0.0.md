# MC 整合包升级助手 v1.0.0 使用说明

## 1. 功能概览
- **自动识别整合包**：支持 PCL2 / PCL-CE 版本目录（`.minecraft\versions\<实例名>`，自动检测版本隔离），也支持直接拖入 `.mrpack`、CurseForge `.zip`、MCBBS `.zip`、MultiMC/Prism `.zip` 与懒人包压缩包。
- **跨版本兼容性检测（适配 `26.1+` 年份制）**：动态拉取 Minecraft 最新版本号与推荐加载器版本，主用 Modrinth（辅以 CurseForge）区分「可升级（正式版）」「仅测试版」「需手动下载」「暂无新版」，并自动递归补齐 `required` 前置依赖与提示冲突。
- **一键并发下载与导出**：边下载边校验 SHA-512 / SHA-1 防止损坏；导出可直接拖入 PCL2 / PCL-CE 安装的标准 `.mrpack` 压缩包（同时支持单独导出原整合包配置备份 `.zip`）。

## 2. 快速上手
1. 双击运行 `MC整合包升级助手-v1.0.0.exe`。
2. **第 1 步（导入整合包）**：把 `.mrpack` / `.zip` 压缩包直接拖入窗口，或点击「选择 PCL2 版本目录」选中 `.minecraft\versions\<你的版本名>`。
3. **第 2 步（版本兼容性）**：选择目标 MC 版本（如 `26.1`、`26.2`）与加载器（如 `Fabric`），点击「开始检测兼容性」。如有需要可在列表中手动切换候选版本、跳过或保留原版。
4. **第 3 步（下载与配置）**：点击「开始下载 Mod」，并在下方勾选需要保留的原配置目录（如 `config/`、`kubejs/`、`options.txt`、`resourcepacks/`、`shaderpacks/` 等）。
5. **第 4 步（导出 PCL2 包）**：点击「导出 PCL2 整合包 (.mrpack)」，将生成的 `.mrpack` 直接拖入 PCL2 / PCL-CE 启动器窗口即可安装。

## 3. 常见问题排查
- **为什么拖入文件到 PCL2 没反应？**
  Windows 下若 PCL2 以「管理员身份运行」，而文件资源管理器是普通权限，系统 UIPI 安全机制会拦截拖放。请取消 PCL2 的管理员权限运行，或在 PCL2 内使用「下载 → 安装整合包 → 选择本地文件」。
- **部分 CurseForge Mod 提示“需手动下载”怎么办？**
  当作者禁止第三方程序直接分发该文件时，工具会先尝试在 Modrinth 寻找同源直链；若无替代，请点击列表中的「下载页」在浏览器手动下载 `.jar` 后，点击「导入」挂载，工具会自动校验后打入 `overrides/mods/`。含此类文件的导出包请勿公开分发，仅限个人本地游玩。
- **提示缺少 WebView2 运行时怎么办？**
  精简版 Windows 若未预装 Microsoft Edge WebView2，程序会弹出引导提示，按提示安装约 1.7MB 的微软官方 Evergreen 运行时即可。
- **网络缓慢或连接失败？**
  右上角「设置」内已默认开启 **MCIM 国内镜像加速**，且支持自动读取 Windows 系统代理或填写自定义 HTTP / SOCKS5 代理；如需识别 CurseForge 专属 Mod，可在设置中填入免费申请的 CurseForge API Key（本地采用 Windows DPAPI 加密存储）。
